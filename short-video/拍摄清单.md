# 拍摄清单（出发前过一遍）

## 设备

- [ ] 手机（电量 ≥ 90%，存储 ≥ 20G）
- [ ] 充电宝 + 备用机（一台拍、一台收音看回放）
- [ ] 手机支架 / 八爪鱼三脚架（自拍固定用）
- [ ] 领夹麦克风（有则更好，风大时必备防风毛套）
- [ ] 镜头布（果园露水多，镜头会糊）

## 场景素材（每条视频都需要的 B-roll）

- [ ] 云雾山景大远景（早上去，晚就没了）
- [ ] 上山路全程跟拍
- [ ] 果树全貌 → 枝叶 → 果子三级景别
- [ ] 手部特写：拨叶、剪果、掰果、装篮
- [ ] 果篮渐满过程（延时或分段）
- [ ] 下山挑担远景
- [ ] 打包场景：分拣、称重、装箱、贴单

## 口播/环境声

- [ ] 环境底噪 30 秒（后期垫底用）
- [ ] 鸟叫、剪刀咔哒、掰果声单独收一条干净版

## 人

- [ ] 穿深色耐脏衣服（红色系出镜显眼，但果园以真实为主，别太"演"）
- [ ] 台词只说短句，长话留给字幕

## 出发前最后确认

- [ ] 当天天气（雨后云雾最佳）
- [ ] 分镜脚本带上了（scripts/ 对应编号）
- [ ] 手机横竖屏设置：**全部竖屏 9:16**
