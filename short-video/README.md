# short-video —— 抖音短视频素材库

> 主角：返乡果农**小勇** · 平台：抖音 · 目标：日常采摘内容起号 → 小黄车带货

## 赛道定位

| 项 | 定位 |
|---|---|
| 人设 | 返乡年轻人，真实、朴实、话不多但真诚 |
| 内容基调 | 原生态记录，不摆拍、不喊麦，用手绘风的字幕包装 |
| 差异点 | 高山果园实景（海拔、云雾、山路）是别人抄不走的画面资产 |
| 首要目标 | **先用免费测试视频验证效果，再决定是否正式投入** |

## 内容支柱（四条轮换）

1. **上山采摘日常**——山路、云雾、摘果手部特写（起号主力）
2. **开箱吃果实测**——掰开、闻香、泡水，馋人向
3. **发货打包的一天**——纸箱、称重、贴单，信任感向
4. **果山四季风景**——纯 B-roll 沉淀素材，备用 filler

## 发布节奏（建议）

| 阶段 | 频率 | 说明 |
|---|---|---|
| 起号期（前 4 周） | 每周 3 条 | 主打采摘日常，摸数据 |
| 复盘后调整 | 视数据 | 哪类完播率高就加密哪类 |

## 目录说明

```
short-video/
├── scripts/              # 分镜脚本（按发布顺序编号）
│   ├── 01-首支测试视频-上山采摘日常.md   ← 全网第一条，最重要
│   ├── 02-开箱吃果实测.md
│   └── 03-发货打包的一天.md
├── 拍摄清单.md           # 出发拍片前的 checklist
└── 数据复盘模板.md        # 每条视频发布 48h 后填写
```

## 制作规范

- 竖屏 9:16，时长 ≤ 60 秒（起号期建议 20~35 秒）
- 前 3 秒必须有钩子（悬念 / 香气 / 山景冲击）
- 字幕统一手绘风格字体，颜色跟随品牌 VI（墨色 #4A3B2A + 果紫 #7B3F98）
- BGM：田园/民谣类，音量压在人声之下
- 每条视频发布 48 小时后填一行《数据复盘模板》，攒够 6 条做第一次复盘
